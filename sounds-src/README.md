# Готовый набор звуков для соундборда

Положите сюда файлы `.mp3`, `.ogg`, `.wav` или `.m4a` (короткие, до 8 секунд и до ~300 КБ — иначе
обрежьте в любом редакторе) и выполните из корня репозитория:

```
npm run sounds:pack
```

Скрипт копирует звуки в `public/sounds/` и пишет `public/sounds/pack.json`. Название на кнопке — из имени
файла (`вайн бум.mp3` → «Вайн бум»), имя звука — латиницей из него же. Пока набор пуст, соундборд играет
вшитые синтезированные звуки; как только в наборе есть хотя бы один — вшитые не показываются.

Рядом с файлами положите `LICENSES.md`: откуда звук и под какой лицензией он свободен — за чужие мемы платят
не деньгами, а претензиями.
