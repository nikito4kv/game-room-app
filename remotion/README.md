# Рекламные ролики Game Room (Remotion)

Ролики собраны кодом: каждый кадр рисуется как обычная веб-страница и склеивается в MP4.
Бренд, цвета и шрифты берутся из дизайн-системы «Эфир» (`design-system/tokens.css`,
переменные `--gr-*`), поэтому ролик выглядит как сам продукт. Весь интерфейс в кадре —
настоящие скриншоты (`public/promo/shots/`) и компоненты, нарисованные по образцу продукта.

## Что получается

| Композиция | Размер | Длина | Куда |
|---|---|---|---|
| `Promo16x9` | 1920×1080 | около 28 с | сайт, YouTube, показ на встречах |
| `Promo9x16` | 1080×1920 | около 25 с | Reels, Shorts, TikTok, истории в Telegram |
| `Teaser9x16` | 1080×1920 | 9 с | короткий крючок: «зови друзей, слышно всех» |
| `Poster` | 1200×630 | картинка | превью ссылок, баннеры, посты |
| `Square` | 1080×1080 | картинка | пост в ленту |

Порядок сцен большого ролика: крючок, боль, ссылка, голос, показ экрана, шумодав, права хоста,
доказательство, призыв. В вертикальном нет сцены «доказательство» (он короче).
Ключевой текст в вертикальных роликах лежит внутри безопасной зоны площадок: сверху 260 px и
снизу 350 px свободны (там интерфейс Reels и TikTok).

## Как поменять тексты (5 минут)

**Все надписи лежат в одном файле: `remotion/copy.ts`.** Откройте, поправьте строки, сохраните.
Больше ничего трогать не нужно.

- `*слова*` в строке красит слова цветом «эфира» (лайм): `"Зови друзей.|*Слышно всех.*"`.
- `|` в строке переносит строку.
- Короткие слова («в», «с», «и», «для») сами склеиваются со следующим, предлог не повиснет.
- Строки, помеченные в файле словом «ПОДТВЕРДИТЬ», надо сверить с итогами исследования рынка.
- Адрес в финале и на картинках: `SHARED.url` в том же файле. Для одного рендера можно подменить
  флагом: `npx remotion render Promo16x9 out.mp4 --props='{"url":"game-room.space"}'`.
- Имена людей за столом и цвета их аватаров: `SHARED.people` (цвет — номер 0–9 из палитры аватаров).

Правила для текстов: только по-русски, простые слова, без выдуманных цифр. В кадре можно
говорить только о том, что есть в продукте (показ экрана 1080p60, звук показа стерео, шумодав, права
хоста, без регистрации, чат с историей, мини-окно поверх игры).

Если текст стал длиннее: заголовки набраны шрифтом Unbounded (он очень широкий), длинное слово
может не поместиться в колонку. Размер заголовка конкретной сцены задаётся в её файле
(`titleSize` в `scenes/*.tsx`), например в `scenes/Pain.tsx`.

## Как отрендерить

Зависимости уже стоят (`npm install --legacy-peer-deps`). Из корня проекта:

```bash
npm run video                  # студия: превью, таймлайн, правка пропсов (http://localhost:3000)
npm run video:render           # большой ролик 16:9  -> video-out/game-room-promo-16x9.mp4
npm run video:render:vertical  # ролик 9:16 и тизер -> video-out/game-room-promo-9x16.mp4, game-room-teaser-9x16.mp4
npm run video:poster           # две картинки        -> video-out/poster-1200x630.png, square-1080x1080.png
```

Папка `video-out/` лежит в `.gitignore` и в git не попадает. Формат: MP4, H.264, качество по
умолчанию Remotion (CRF 18). Один кадр на проверку:
`npx remotion still Promo9x16 video-out/кадр.png --frame=300`.

Самый первый рендер сам скачает Chrome Headless Shell (около 100 МБ), дальше он берётся из кэша.
Рендер грузит процессор: большой ролик занимает несколько минут.

## Где что лежит

| Путь | Что это |
|---|---|
| `remotion/copy.ts` | **все тексты** |
| `remotion/Root.tsx` | список композиций, размеры, импорт токенов |
| `remotion/fonts.ts` | загрузка Unbounded и Onest из `public/promo/fonts/` (с повторами) |
| `remotion/compositions/` | `Promo.tsx` (раскадровки 16:9 и 9:16), `Teaser.tsx`, `Stills.tsx` |
| `remotion/scenes/` | сцены: `Hook`, `Pain`, `Invite`, `Voice`, `Screen`, `Noise`, `Host`, `Proof`, `Cta` |
| `remotion/components/` | стол и аватары, окно браузера, игровая заглушка, мини-комната, шумодав, текст |
| `public/promo/shots/` | настоящие скриншоты макетов продукта, @2x |
| `public/promo/fonts/` | копии шрифтов из `assets/` (лицензия OFL) |
| `video-out/` | готовые файлы |

Длины сцен — массивы `PLAN_WIDE` и `PLAN_TALL` в `compositions/Promo.tsx` (число кадров, 30 в секунду).
Изменили длину — остальное сдвинется само.

## Скриншоты интерфейса

Скриншоты сняты с макетов `/design/*` на своём dev-сервере. Чтобы переснять после смены дизайна:

1. Запустить сервер на отдельном порту, не мешая обычной работе:
   `$env:NEXT_DIST_DIR='.next-video'; npx next dev -p 3201` (PowerShell).
2. Открыть `http://localhost:3201/design/room`, `/design/lobby` и т. д. (именно `localhost`, не `127.0.0.1`)
   и снять PNG в @2x (Playwright, окно 1440×900, масштаб 2) в `public/promo/shots/`.
3. Остановить сервер.

В макете чата есть ссылка на чужой сервис; перед съёмкой её заменяют на `game-room.space/room/K7QMP4`
(правится только текст на странице при съёмке, исходники продукта не меняются).

«Игровой» кадр в сцене показа экрана рисуется кодом (`components/GameScreen.tsx`): абстрактная сетка и
фишки, без чужих торговых марок и скриншотов чужих игр.

## Подводные камни

- Версии `remotion` и `@remotion/cli` в `package.json` должны совпадать. Обновлять вместе:
  `npx remotion upgrade`.
- `ajv@^8` в `devDependencies` стоит намеренно: без него сборка Remotion падает на
  `Cannot find module 'ajv/dist/compile/codegen'`. Не удалять.
- `next/font` в Remotion не работает, шрифты грузятся вручную в `fonts.ts`. Там же выставляются
  переменные `--font-unbounded` и `--font-onest`: без них шрифты из токенов не подхватываются, и текст
  рисуется шрифтом с засечками. Загрузка идёт с повторами (`retries`), убирать их не надо.
- У Onest нет жирных начертаний, используются только 400 и 500.
- `Still` в Remotion имеет 1 кадр в секунду, и пружины анимации в нём считаются неверно, поэтому
  `Poster` и `Square` сделаны обычными композициями из одного кадра, который «перемотан» на готовое состояние.
- Tailwind в видео не подключён: стили инлайновые, на переменных `--gr-*`.
- Тексты внутри скриншотов поменять нельзя, это картинки. Если в продукте поменялся интерфейс, надо переснять.
